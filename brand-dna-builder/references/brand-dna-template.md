## Template Rules

1. **Every value must come from real data.** Website extraction or user interview only. No defaults, no placeholders, no "[brand values]" left unfilled.

2. **Leave sections blank if you don't have data.** Better to have a partial file than a file full of invented content. Other skills will handle missing data gracefully.

3. **Use exact quotes for hero headlines, taglines, and value props.** These are verbatim extractions, not paraphrases.

4. **Keep descriptions concise.** 1-2 sentences per section. This file is read by other skills as context — keep it scannable.

5. **Date the file.** So the member knows when to refresh it.

6. **Always include the "Next skills to run" metadata.** This helps guide the member through the onboarding flow.
